# 정답 라벨 기준

공고 하나에 세 가지를 판정합니다. 제목·설명·주최·자격·상금 등 공고에 적힌 정보로만 판단하고, 원문 링크를 열어 확인해도 됩니다.
모델(Jev)과 키워드 규칙의 판정은 보지 않고 라벨을 답니다.

## 1. ai — AI 대회인가? (예/아니오)

**예**: 참가자가 AI를 만들거나·쓰거나·제안해야 하거나, 대회 주제가 AI인 경우.
- AI/인공지능/머신러닝/딥러닝/LLM/생성형 AI 모델 개발, 데이터 분석·예측 모델링 경진대회
- 생성형 AI로 만든 영상·이미지·음악 공모전 (AI 사용이 조건이거나 부문이 따로 있음)
- AI 서비스·활용 아이디어, AI 스타트업 창업경진대회, AI 해커톤

**아니오**:
- AI가 전혀 없거나, 홍보 문구에 한 번 스치듯 나올 뿐 대회 내용과 무관한 경우
- 일반 SW 개발·코딩·앱 공모전으로 AI가 조건이 아닌 경우 ("SW 사생대회", "알고리즘 대회"는 아니오)
- 일반 데이터 "활용" 공모전: 공공데이터로 아이디어/시각화만 내는 경우는 아니오, 예측·분석 모델을 만드는 경우는 예
- 판단이 정말 불가능하면 `unsure`로 두고 메모를 남깁니다 (지표 계산에서 제외)

## 2. contest — 지금 참가자를 모집하는 대회인가? (예/아니오)

**예**: 공모전·경진대회·해커톤·챌린지·창업경진대회의 참가 접수 공고.

**아니오**: 교육·강의·부트캠프·세미나·설명회·행사 참가 모집, 채용, 서포터즈/기자단, 결과 발표·시상식 소식.

## 3. category — 어떤 대회인가? (하나 선택)

| 값 | 뜻 |
|---|---|
| hackathon | 해커톤, 아이디어톤 등 정해진 시간 안에 팀으로 만드는 대회 |
| startup | 창업, 사업계획, 사업화, 투자·IR 경진대회 |
| tourism | 관광·여행·MICE 주제 |
| academic | 논문, 학술, 연구 대회 |
| data | 데이터 분석, 데이터 사이언스, 머신러닝 모델링 대회 |
| creative | 영상, 이미지, 음악, 디자인, 글, 웹툰, 캐릭터, 광고 등 창작 공모전 |
| youth | 어린이·청소년·학생만 참가할 수 있는 대회 |
| dev | SW 개발, 코딩, 앱/웹, 로봇, 보안 대회 |
| idea | 아이디어, 정책 제안, 기획 공모전 |
| other | 위에 해당 없음 |

관광·여행·MICE가 주제인 공모전은 제출물이 사진·영상·기념품이어도 **tourism**입니다
(사이트가 관광 분야를 따로 모아 보여주기 때문입니다. 단, AI·데이터 모델링 대회는 data).

그 밖에 여러 개가 맞으면 **참가자가 실제로 제출하는 것**에 가장 가까운 것을 고릅니다
(예: "청소년 AI 영상 공모전" → creative, "대학생 AI 해커톤" → hackathon).
대상이 청소년으로 한정돼도 제출물 성격이 뚜렷하면 그쪽을 고르고, 제출물이 모호할 때만 youth를 씁니다.
